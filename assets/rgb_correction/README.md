# RGB-Correction Assets

No RGB-correction image dataset, denoiser checkpoint, feature cache, fitted
third-party model, or large per-image result archive is committed to ordinary
Git.

This directory is reserved for release instructions and checksum manifests. If
a future Release distributes a derived artifact, it must include:

- the upstream source and redistribution basis;
- a versioned SHA-256 manifest;
- the exact protocol or result mapping;
- a statement of whether the artifact contains images, weights, features, or
  derived scores; and
- license and notice text separate from the repository's Apache-2.0 terms.

SIDD/SIDD+, PolyU, CC-noise, NIND, RENOIR, DND, and all third-party model
parameters remain subject to their own providers' terms.
